Účtenka
=======

Program vytiskne účtenku jako z obchodu.
Potřebujete Javu 17 nebo novější: https://adoptium.net

Spuštění
  Windows: dvakrát klikněte na uctenka.cmd
  Jinde:   java -jar uctenka.jar  (spusťte ve složce s tímto souborem)

Jak vytvořit účtenku
  1. Napište název zboží a stiskněte Enter.
  2. Napište počet kusů (jen Enter = 1 kus).
  3. Napište cenu za kus, např. 24,90.
  4. Další zboží zadejte stejně. Až máte vše, stiskněte Enter na prázdném řádku.
  5. Napište, kolik se zaplatilo. Účtenka se vytiskne.

Vlastní obchod
  Otevřete obchod.properties v Poznámkovém bloku a přepište údaje za "=":
  nazev, adresa, ico, dic, dph (sazba v %), paticka (text dole).

Receipt
=======

The program prints a receipt like the ones you get in a shop.
You need Java 17 or newer: https://adoptium.net

Running
  Windows:  double-click uctenka.cmd
  Anywhere: java -jar uctenka.jar  (run it in the folder with this file)

How to make a receipt
  1. Type the item name and press Enter.
  2. Type the quantity (just Enter = 1 piece).
  3. Type the price per piece, e.g. 24,90.
  4. Add more items the same way. When done, press Enter on an empty line.
  5. Type how much was paid. The receipt is printed.

Your own shop
  Open obchod.properties in Notepad and change the values after "=":
  nazev (name), adresa (address), ico and dic (company IDs),
  dph (VAT rate in %), paticka (text at the bottom).

الوصل
=====

البرنامج يطبع وصل كيما تاع الحانوت.
لازمك Java 17 ولا جديدة عليها: https://adoptium.net

التشغيل
  Windows: دير double-click على uctenka.cmd
  وين ما كان: java -jar uctenka.jar  (شغّلو في الدوسي اللي فيه هذا الفيشي)

كيفاش تدير وصل
  1. اكتب اسم السلعة وانقر Enter.
  2. اكتب شحال من حبة (غير Enter = حبة وحدة).
  3. اكتب السومة تاع الحبة، مثلا 24,90.
  4. زيد السلع لخرين بنفس الطريقة. كي تكمل، انقر Enter في سطر فارغ.
  5. اكتب شحال تخلّص. الوصل يتطبع.

الحانوت تاعك
  حل obchod.properties في Notepad (Bloc-notes) وبدّل واش كاين من بعد "=":
  nazev (الاسم)، adresa (العنوان)، ico و dic (أرقام الشركة)،
  dph (نسبة TVA بـ %)، paticka (الكتابة اللي لتحت).
